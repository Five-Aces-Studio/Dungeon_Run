# UI Design System — Dungeon Run

## Scene convention

Prototype and validate UI in `SceneVictorLab`.
Integrate approved UI into `SceneVictor` only when explicitly requested.

## Rendering separation

Keep gameplay UI/text crisp and separate from destructive world pixel-rendering passes.

## Core combat readability

The UI should clearly expose:
- 5-card hand
- exactly 2 action slots
- player HP/status
- enemy intent/status
- selected targets

Significant UI work requires Game View visual verification.
