# Combat HUD V4 art sources

All sprites in this folder (except `Fonts/` and `TMP/`) are generated by the deterministic
procedural painter in `Tools/CombatHUDV4Painter/`. No image-generation service, no stock art
and no third-party or reference artwork was used or copied.

- Generator: `python Tools/CombatHUDV4Painter/paint_hud_v4.py --all` (from the repo root).
- Seed: `4242`; each sprite derives its own RNG from a SHA-256 hash of its name, so a sprite is
  reproducible on its own (`--only <group> --name <substring>`).
- Authoring size: 2x the 1920x1080 reference (a sprite shown at 118x158 is painted at 236x316).
- Read-only inputs:
  - `Assets/Art/Rendering/AcrylicV3/T_DungeonRun_PaintStrokes.png` (the world brush-stroke
    texture, sampled as UI brush grain so the HUD shares the world's strokes);
  - `Assets/Art/UI/CombatHUDV3/{Attack,Defence,Dodge,Heal,Piercing}Icon.png` (Dungeon Run's own V3
    ink icons, recoloured to the warm ink and lightly grained for `Icons/`; the sword, arcs and boot
    parts are recomposited for `Icons/ComboIcon.png` and `Icons/CounterattackIcon.png`);
  - `Assets/Art/UI/CombatHUDV4/Fonts/` (the Alegreya SC "?" outline inside `Enemy/IntentUnknown.png`
    and the unknown-intent glyph; mock composites and tests also rasterise text with it).
- Painted from scratch in the same ink weight: `Icons/ChargeIcon.png` (clock), `Icons/MissIcon.png`
  (swipe arcs and dust puff), every `Glyphs/` sprite, and all frames, plates, sockets, tokens,
  tracks, banners and washes.
- The layout table the installer consumes, `Assets/Settings/CombatHUDV4/HudLayoutV4.json`, is
  written by the same command.
- Fonts: see `Fonts/FONT_SOURCES.md` (Alegreya SC / Alegreya Sans, SIL OFL 1.1).
